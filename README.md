# Maintor — AI Learning Platform

Your learning partner that helps you actually finish.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:8080/maintor-launchpad/](http://localhost:8080/maintor-launchpad/) to view the landing page.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide Icons

## Deployment

Build for production:

```bash
npm run build
```

Deploy to GitHub Pages by pushing the `dist` contents to the `gh-pages` branch.
